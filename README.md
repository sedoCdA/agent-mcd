# McDonald's Crew Support Voice Agent

An agentic AI voice assistant that handles internal IT/ops support calls 
from McDonald's crew members. Replaces redundant human support calls with 
a real-time voice bot that resolves issues using a knowledge base, 
prioritizes tickets (P1–P4), escalates when needed, and logs all sessions.

## Tech Stack
- STT: Deepgram
- LLM: Claude (Anthropic)
- RAG: FAISS + LangChain
- TTS: ElevenLabs
- Logging: Python CSV
